- Live: https://hatlem72-creator.github.io/hea3103-k45/
- Alle: [HEA3103-ovingssamling.pdf](HEA3103-ovingssamling.pdf)

Oppgavetekster fra Udir og åpne øvingseksempler. Eksempelsvar er skrevet som vanlige eksamenstekster med sikte på et nivå mellom karakter 4 og 5 (uoffisielt, ingen karaktergaranti) og er ikke offisielle fasitsvar.
